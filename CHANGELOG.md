# Changelog

## 0.1.3

- Hide the text caret on the native time picker clock button and use a pointer cursor without disabling the picker.

## 0.1.2

- Hide stray browsing carets on non-editable card, dialog and configuration editor content.
- Preserve visible input carets and keyboard focus indicators.

## 0.1.0

- Introduce an independent Deye Time of Use battery schedule card with six compact rows.
- Derive all interval boundaries from live time entities, including the last-to-first overnight interval.
- Add start-time and SOC draft dialogs, native keyboard/touch controls and a six-program visual editor.
- Add state-confirmed commands, per-program duplicate prevention, timeout and isolated unavailable/error handling.
- Support Home Assistant Sections, light/dark themes, reduced motion and narrow screens.
- Include a mock preview, unit/browser tests and HACS-compatible release packaging.
